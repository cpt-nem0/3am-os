# Design System: 3AM OS (Vaporwave OS)

## Vibe & Concept
"Vaporwave OS". A nostalgic, retro-computing aesthetic that feels like booting up an old Windows 95 or Classic Mac machine at 3 AM. It blends classic UI elements (window frames, pixel art) with dreamlike, surreal vaporwave colors.

## Typography (Curated Retro)
*   **Primary Display / Headers:** `Silkscreen` or `VT323` (Clean, highly legible pixel fonts that scream early internet/arcade) or `Chakra Petch` (if you want a more retro-futuristic tech UI vibe).
*   **Window Titles / Accents:** `VCR OSD Mono` (Classic camcorder glitch font) or `Courier Prime`.
*   **Body Text:** `Space Mono` or `IBM Plex Mono`. (Using monospace fonts for the body keeps the "operating system" illusion intact while remaining highly readable).

## Color Palette: Light Mode (Daytime Surfing)
*   **Background (Desktop):** Classic OS Gray `#C0C0C0` or Pale Grid Cyan `#E0F8F5`
*   **Window Backgrounds:** Pure White `#FFFFFF`
*   **Window Title Bars:** Classic Win95 Blue `#000080`
*   **Primary Accent:** Bubblegum Pink `#FF85B3`
*   **Secondary Accent:** Lavender `#B399FF`
*   **Text (Body):** Black `#000000`
*   **UI Shadows/Highlights:** True White `#FFFFFF` (top/left bevels) and Dark Gray `#808080` (bottom/right bevels)

## Color Palette: Dark Mode (Midnight Surfing)
Dark Mode is the SAME design as Light Mode — identical layout, components, and 3D beveled skeuomorphic styling — only the colors change. It is strictly a palette swap, not a different aesthetic (no neon wireframes, no glowing outlines, no cyberpunk styling).
*   **Background (Desktop):** Deep Grid Purple `#120424`
*   **Window Backgrounds / Chrome:** Dark Charcoal `#2B2B2B`
*   **Window Title Bars:** Classic Win95 Blue `#000080` (same as Light Mode)
*   **Primary Accent:** Bubblegum Pink `#FF85B3` (same as Light Mode)
*   **Secondary Accent:** Lavender `#B399FF` (same as Light Mode)
*   **Text (Body):** Off-White `#EAEAEA`
*   **UI Shadows/Highlights:** Same 3D bevels as Light Mode, adapted for dark surfaces: Light Gray `#555555` (top/left bevels) and Near-Black (bottom/right bevels).

## UI Components & Styling
*   **Containers:** Mini-projects sit inside "Windows". Every card needs a top title bar (with a minimize/maximize/close button trio).
*   **Buttons:** Thick, 3D beveled borders in both modes (looks physical to click). Dark Mode uses the dark-adapted bevel colors.
*   **Icons:** Pixel-art style (e.g., a pixelated folder, floppy disk, or hourglass).
*   **Decorations:** Subtle scanline overlays (horizontal lines with very low opacity), 3D wireframe grids in the background, or classical statues.

## Layout (The Hub)
*   The Hub acts as the "Desktop". 
*   Projects aren't arranged in a perfect modern grid; they are placed like desktop icons or cascading application windows.
